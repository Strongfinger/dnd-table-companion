# กิลด์ Agent (Agent guild)

หน้าภาพเคลื่อนไหวที่แสดงว่า agent แต่ละตัวกำลังทำอะไร ตำแหน่งบอกสถานะ:
ยืนที่โต๊ะทีม = กำลังทำงาน · เดินมาที่โต๊ะ Tan (กระดิ่งดัง) = รอ Tan · นั่งพักหน้าเตาผิง = ว่าง

ไฟล์ `guild.html` ไฟล์เดียวใช้ได้ 3 แบบ เลือกเองตามที่เปิด:

| เปิดที่ไหน | ข้อมูลมาจาก | ความเร็ว |
|---|---|---|
| บอร์ด [ทีม Agent ของ Tan](https://claude.ai/artifact/3yEQREAwjGXPvKyQtFvxdP) | thread ในโปรเจกต์เขียนสถานะลงบอร์ด (ดู docs/TEAM.md) | ขยับภายในไม่กี่วินาทีหลัง thread เขียน แต่ thread เขียนแค่ขั้นหลัก |
| `http://127.0.0.1:4777` บน Mac | hook ของ Claude Code ผ่าน `server.py` | ทุกครั้งที่ Claude เรียก tool เห็นเฉพาะงานบน Mac |
| เปิดไฟล์ตรง ๆ | ข้อมูลจำลอง (ไว้ดูหน้าตา) | เล่นวนเอง |

## ใช้บน Mac

ต้องมี `python3` และ `curl` (มีใน macOS อยู่แล้ว) ไม่ต้องลงไลบรารีเพิ่ม

1. ติดตั้ง hook ครั้งเดียว: `python3 install.py`
   - เพิ่ม hook 10 ตัวใน `~/.claude/settings.json` (สำรองไฟล์เดิมไว้ก่อนทุกครั้ง)
   - hook แค่ส่ง event ไปที่ `127.0.0.1:4777` แบบเบื้องหลัง ถ้าไม่ได้เปิดเซิร์ฟเวอร์ไว้ ก็ไม่มีผลอะไรกับ Claude Code
   - มีผลกับ session ใหม่ของ Claude Code
2. เปิดกิลด์: ดับเบิลคลิก `open-guild.command` (หรือรัน `python3 server.py` แล้วเปิด http://127.0.0.1:4777)
   - หน้าต่าง Terminal ต้องเปิดค้างไว้ ปิดหน้าต่าง = ปิดกิลด์
3. ใช้ Claude Code ตามปกติ ตัวละครจะขยับเอง
   - session หลักเป็นตัวละครสีส้ม "Claude" ที่โต๊ะ Claude Code
   - subagent ที่ชื่อตรงกับทีม (เช่น `developer`, `qa-tester`) ไปยืนที่โต๊ะทีมของตัวเอง
   - subagent อื่น (Explore, Plan, general-purpose) เป็นตัวละครสีเทาที่โต๊ะ Claude Code
   - ขออนุญาตใช้ tool = เดินมาที่โต๊ะ Tan

ข้อมูลอยู่ในหน่วยความจำของ `server.py` เท่านั้น ไม่เขียนลงดิสก์ และเปิดรับเฉพาะจากเครื่องตัวเอง (127.0.0.1)

## เอาออก

`python3 install.py --uninstall` ลบเฉพาะ hook ของกิลด์ hook อื่นใน settings ยังอยู่ครบ

เปลี่ยนพอร์ตได้ด้วย `AGENT_GUILD_PORT=5000` (ต้องตั้งทั้งตอน install และตอนเปิดเซิร์ฟเวอร์)
